# 当前改动与验证记录

本目录保存 2026-10-18 的实现及设备验证记录。各记录中的构建标记、包名、哈希与测试结果属于该次交付，不能直接视为当前版本的验证结果；部分方案已被后续调整取代。

## 当前代码相对 3154694 的主要变化

- **连接卡片编辑**：允许组内子卡片单独移动和调整宽高；自身文字/笔迹决定最小尺寸，相邻活动桥及桥上可见笔迹共同限制操作范围。通过历史变更提交，保留组合选区、撤销与保存。
- **连接约束**：使用局部 Region 遮罩替代复杂笔迹的 Path.op 合并，避免此前真实压感笔迹触发的主线程 ANR；拖动时绘制桥和笔迹预览。
- **手写交接**：保持停笔 3000ms 后交接，悬停、重新配置和背景同步覆盖整段等待窗口，移除每次落笔强制重发颜色配置。
- **刷新与显示**：移除直接写 e-ink 缓冲区的局部黑白清理及其积压队列，改用最终稳定帧 UI Regal 请求；JNI 保留显示忙碌状态读取。当前长按选卡/套索持有 A2，实际拖动临时用 AUTO，松手回 A2；宽高调整仍用 A2。静态卡片灰色加深。
- **卡片手势**：连续书写中的直线可识别为拉出/连接手势，横向拉出新卡使用源卡高度作为新卡宽度，图片卡允许方括号扩边。
- **构建与检查**：新增 Unix `buildPlugin.sh`、独立 Android 进程的尺寸/连接/交接/刷新模式检查，以及交付记录；修正 NoteSession 属性 setter 与方法的 JVM 命名冲突。

当前刷新策略以 CLAUDE.md 的“刷新模式”和源码为准（套索整段 FullUiAuto、拖动按 Regal 开关；画布平移缩放恢复 3154694 的 A2 与黑白清理），[卡片拖动 AUTO、套索保持 A2](card-auto-lasso-a2.md) 已被取代；连接约束及交接修复见 [连接卡片安全修复](connected-card-safe.md)。其他模式切换文档为历史记录。

## 当前已知问题

以下问题已由用户报告，当前提交保留现场，未包含后续修复：

1. 卡片拖动开始时背景会短暂闪隐。代码先隐藏内容层中的卡片/桥并创建预览，随后从初始 A2 切到 AUTO；交接与模式变化需进一步设备验证。
2. AUTO 拖动仍使用 A2 的黑白网点预览；连接桥预览未裁除静止邻卡覆盖范围。用户报告连接场景中卡片变黑，纯黑现象的具体触发点尚未完成设备核对。
3. 独立移动连接子卡时，每个 MOVE 都进行连接边界检查并重建桥上笔迹的屏幕路径。之前已修复卡死，但每次移动的计算与分配开销仍可能造成卡顿。

## 构建与验证边界

按项目约定使用 `buildPlugin.sh --with-logs`。仓库缺少部分 React 源文件，当前本地构建使用 `MOSAIC_USE_EXISTING_BUNDLE=1` 沿用已有 bundle，并设置 `MOSAIC_NDK_VERSION=27.0.12077973` 选择本地 NDK。这不代表从干净检出即可完整重建 JS。

`tools/` 中的检查程序需对相应 APK 编译为 DEX 后，通过设备 `app_process` 执行。真实场景回放由调用者提供本地副本，不随仓库提交用户白板。构建产物、依赖、设备日志与逆向提取文件不纳入此次提交。
